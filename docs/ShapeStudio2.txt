        "star" | "heart" | "pointer" | "icon" | "image";
  imageUrl?: string;
  x: number;
  y: number;

  height: number;
  rotation: number;     // Degrees (0..360)
  opacity: number;      // 0.0 to 1.0
  zIndex: number;
  fillColor: string;    // Hex / RGBA
  strokeColor: string;  // Hex / RGBA
  strokeWidth: number;
  borderRadius?: number;
  lineStyle: "solid" | "dashed" | "dotted";
  text?: string;
  fontSize?: number;
  fontFamily?: string;
  textColor?: string;
  textAlign?: "left" | "center" | "right";
  isBold?: boolean;
  isItalic?: boolean;

### 6. HTML5 Canvas Render & Composition Pipeline
ShapeStudio uses a dual-rendering approach:
1. **Interactive SVG & DOM Overlay Stage**: Renders active vector layers, transform bounding boxes, rotation handles, and tail control points using high-performance React components inside `stageRef` for sub-pixel accuracy and real-time interaction.
2. **Offscreen Canvas Bake Engine**: When baking a frame or exporting PNG assets, `renderFrameToCanvas()` compiles all layers into a single 2D Canvas context (`CanvasRenderingContext2D`):

```
Rendering Pipeline Sequence:
1. Clear Offscreen Canvas (width = baseImage.naturalWidth, height = baseImage.naturalHeight).
2. Draw Base Image Frame (ctx.drawImage).
3. Render Freehand Lines Stack:
   - Iterate lines -> beginPath() -> move/lineTo points -> stroke().
   - Apply special pen shapes (dots, stars, sparkles, spray particles) along bezier curve interpolation.
4. Render Vector Layer Stack sorted by zIndex ascending:
   - Save context state (ctx.save()).
   - Apply transforms: ctx.translate(layer.x + w/2, layer.y + h/2) -> ctx.rotate(rotRad) -> ctx.translate(-w/2, -h/2).
   - Draw Shape / Path (Rect, Circle, Star, Heart, Arrow) with fillStyle & strokeStyle.
   - For Speech Bubbles: Path bubble body -> compute tail path to bubbleTail point -> fill & stroke combined path.
   - For Text: Measure text wrapping -> set font string -> fillText / strokeText.
   - Restore context state (ctx.restore()).
5. Export Result: canvas.toDataURL("image/png") or canvas.toBlob().
```
